## 📖 프로젝트 개요
본 프로젝트는 중학교 1학년 사회 교육과정의 **'법의 의미와 재판의 종류'** 및 **'사법부와 공정한 재판'** 단원을 학생들이 흥미롭게 배울 수 있도록 제작된 파스텔 톤의 단계별 웹 시뮬레이션 게임입니다.

부드러운 파스텔 컬러와 귀여운 동물 캐릭터(토끼 판사, 여우 검사, 곰 변호인, 아기 다람쥐 피고인 등)와 함께 재판의 절차와 헌법상 기본 원칙을 직접 체득할 수 있습니다.

---

## 🎮 게임 단계 (Stages)
1. **Stage 0: 입학식 (인트로)**
   - 토끼 판사 바니와의 만남 및 학습 목표 안내
   - [📖 교사용/학생용 핵심 쏙쏙 요약장] 모달 탑재
2. **Stage 1: 어떤 재판을 열어야 할까?**
   - 민사 재판 vs 형사 재판 분류 챌린지 (사건 의뢰서 5종 해결)
   - 원고/피고 vs 검사/피고인의 차이 피드백
3. **Stage 2: 법정의 자리를 찾아줘!**
   - 실제 법정 좌석 배치 퍼즐 (판사석, 검사석, 피고인·변호인석, 증인석, 방청객석)
   - 사법권의 독립 및 법정 구성원의 고유 역할 매칭
4. **Stage 3: 사건의 진실을 밝혀라!**
   - 숲속 베이커리 황금 딸기 케이크 도난 사건 모의재판
   - **무죄 추정의 원칙**과 **증거 재판주의**(발자국, CCTV, 목격자 진술 조사)
   - 법봉 3타격(탕! 탕! 탕!) 무죄 판결 선고 체험
5. **Stage 4: 억울할 땐 어떡하죠? (3심제 모험)**
   - 1심(지방법원) ➔ 항소(抗訴) ➔ 2심(고등법원) ➔ 상고(上告) ➔ 3심(대법원) 심급 제도
   - 3심제를 두는 궁극적 목적(신중한 판결 및 국민의 기본권 보장) 학습
6. **Stage 5: 골든벨 퀴즈 & 명예 판사 임명장**
   - 중1 사회 핵심 개념 5문항 퀴즈
   - 학생 이름을 입력하여 공식 '명예 판사 임명장' 발급 (인쇄/PDF 저장 지원)

## ✨ 기술적 특징
- **100% 무의존 순수 웹 기술**: 외부 라이브러리나 CDN 연결 없이도 단독 실행 가능
- **Web Audio API 내장 사운드 엔진**: 오디오 파일 다운로드 없이 브라우저 자체 합성 음향(법봉 타격음, 정답음, 팡파레 등) 지원
- **반응형 & 전자칠판 지원**: PC, 스마트폰, 크롬북, 교실 대형 전자칠판(전체화면 지원) 완벽 대응
- **수업 연계 자료 제공**: `수업_지도안_및_활동지.html`을 통해 1차시 45분 수업 지도안 및 학생 배부용 인쇄 학습지 동시 제공
